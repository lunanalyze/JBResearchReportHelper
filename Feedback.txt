# 조사연구 자동화 client feedback

- item list 에 키워드 column 추가
- 초기화 -> 키워드 편집 -> 수집 시 키워드 반영 x
- 키워드 필터가 아예 적용되지 않았을 경우에도 item이 수집되는 문제
- 네트워크 설정 안되어있는데 수집 or 기사 링크 이동 or 보고서 생성 요청할 경우 "네트워크가 끊겼습니다." message 출력(pdf 열기는 가능)
- 보고서 양식 반영 (맑은 고딕, 표 반영)
- 수집 시 item list에서 기본적으로 날짜 기준 오름차순 sorting
- item(수집 자료) list column마다 필터 기능 추가
- 종료 버튼 제거
