# 조사연구 도우미

`조사연구 도우미`는 뉴스, 국가기관 정책자료, 금융연구소 보고서를 수집하고 주간 보고서 작성을 지원하는 Windows용 로컬 앱입니다.

앱은 사용자의 PC에서 실행되며, 수집 자료와 실행 기록은 사용자 PC의 `%LOCALAPPDATA%` 아래에 저장됩니다.

## 다운로드 및 설치

1. GitHub Releases에서 `ResearchReportHelperSetup.exe` 파일을 다운로드합니다.
2. 다운로드한 설치 파일을 실행합니다.
3. 설치가 완료되면 시작 메뉴 또는 바탕화면 바로가기를 통해 `조사연구 도우미`를 실행합니다.
4. 앱 실행 후 브라우저가 열리며 로컬 주소 `http://127.0.0.1:8765`에서 화면을 사용할 수 있습니다.

Windows 보안 경고가 표시될 수 있습니다. 내부 배포 파일이 맞는지 확인한 뒤 조직 보안 정책에 따라 실행하세요.

## 주요 기능

- 뉴스, 국가기관 자료, 금융연구소 보고서 수집
- 뉴스 검색 키워드 및 검색 필터 편집
- 여러 뉴스 수집 기간을 추가하여 기간별 수집 건수 조정
- 수집 결과 미리보기 및 선택 항목 관리
- 선택한 자료만 기반으로 보고서 생성
- 생성된 보고서 열기 및 재생성
- 실행 기록 불러오기 및 삭제
- 보고서 템플릿과 프롬프트 파일을 로컬에서 수정 가능

## 기본 사용 방법

### 1. 자료 수집

화면 상단에는 `뉴스`, `국가기관`, `금융연구소` 카드가 있습니다.

- 각 카드의 `자료 수집` 버튼을 누르면 해당 섹션만 수집합니다.
- `일괄 수집` 버튼을 누르면 뉴스, 국가기관, 금융연구소 자료를 한 번에 수집합니다.
- 개별 수집을 여러 번 실행하면 현재 실행 기록에 자료가 추가됩니다.
- `초기화` 버튼을 누르면 현재 화면의 수집 목록과 상태가 초기화됩니다.

뉴스 수집은 여러 기간을 나누어 설정할 수 있습니다. 기간을 추가하면 이전 기간보다 하루 전 날짜가 기본값으로 들어가며, 기간별로 `은행/지주사 최대 건수`와 `그외 최대 건수`를 지정할 수 있습니다.

### 2. 검색 키워드 편집

뉴스 카드 우측 상단의 `검색 키워드` 버튼을 누르면 키워드 편집 팝업이 열립니다.

- `은행/지주사` 탭과 `그외` 탭을 따로 관리합니다.
- 키워드 목록에서 키워드를 추가하거나 삭제할 수 있습니다.
- 키워드 블록을 클릭하면 선택 상태가 됩니다.
- `검색 필터 추가`는 선택한 키워드를 각각 OR 조건으로 추가합니다.
- `그룹 추가`는 선택한 키워드들을 AND 조건으로 묶어 하나의 검색 필터로 추가합니다.
- 검색 필터끼리는 OR 조건으로 검색됩니다.
- 검색 필터의 키워드 블록을 클릭하면 해당 필터에서 제거됩니다.
- 키워드 블록은 드래그하여 순서를 바꿀 수 있습니다.

예를 들어 아래와 같이 설정할 수 있습니다.

```text
["전북은행" AND "리스크"] OR ["전북은행" AND "금리"] OR ["JB금융"]
```

### 3. 수집 결과 확인

수집이 완료되면 하단 목록에 자료가 표시됩니다.

- `뉴스 그외`
- `뉴스 은행/지주사`
- `국가기관`
- `금융연구소`

목록 우측의 열기 버튼을 누르면 뉴스 원문 또는 PDF 파일을 확인할 수 있습니다.

보고서에 포함할 자료만 체크 상태로 남겨두세요. 체크되지 않은 자료는 보고서 생성 시 제외됩니다.

### 4. 보고서 생성

자료를 선택한 뒤 `보고서 생성` 버튼을 누르면 보고서 생성이 시작됩니다.

- 체크된 자료만 보고서 생성에 사용됩니다.
- 체크되지 않은 자료는 해당 실행 기록 폴더에서 삭제됩니다.
- OpenAI API 키가 필요한 경우 입력 화면이 표시됩니다.
- 보고서 생성이 완료되면 `보고서 열기` 버튼이 활성화됩니다.
- 이미 보고서가 생성된 실행 기록을 불러오면 버튼명이 `보고서 재생성`으로 바뀝니다.
- `보고서 재생성`을 누르면 기존 결과물을 새 결과물로 대체합니다.

국가기관 또는 금융연구소 자료 없이 보고서를 생성하면 확인 알림이 표시됩니다. 사용자가 확인하면 해당 섹션은 비운 상태로 보고서가 생성됩니다.

## OpenAI API 키

보고서 생성에는 OpenAI API 키가 필요합니다. 자료 수집만 할 때는 API 키가 필요하지 않습니다.

처음 보고서를 생성할 때 API 키를 입력하면 로컬 PC에 저장됩니다. 이후 접속 시에는 `기존 api key 사용` 또는 `새 api key 입력` 중 선택할 수 있습니다.

API 키 파일은 아래 위치에 저장됩니다.

```text
%LOCALAPPDATA%\ResearchReportAutomation\config\openai_key.bin
```

API 사용량 및 비용은 API 키 소유자에게 청구됩니다.

## 실행 기록

`실행 기록` 버튼을 누르면 기존 수집 및 보고서 생성 기록을 불러올 수 있습니다.

- 실행 기록을 선택하면 당시의 수집 자료 목록이 복원됩니다.
- 보고서가 생성된 기록은 보고서 상태가 함께 표시됩니다.
- 좌측 체크박스로 여러 실행 기록을 선택할 수 있습니다.
- `삭제` 버튼을 누르면 선택한 실행 기록과 관련 파일이 함께 삭제됩니다.

실행 기록은 아래 폴더에 저장됩니다.

```text
%LOCALAPPDATA%\ResearchReportAutomation\runs
```

각 실행 기록은 `YYMMDD_HHMM` 형식의 폴더로 관리됩니다.

## 저장 위치

앱 설치 파일과 사용자 데이터는 분리되어 관리됩니다.

| 구분 | 위치 | 설명 |
| --- | --- | --- |
| 설치 경로 | `%LOCALAPPDATA%\Programs\ResearchReportHelper` | 앱 실행 파일이 설치되는 위치 |
| 사용자 데이터 | `%LOCALAPPDATA%\ResearchReportAutomation` | 설정, 실행 기록, 보고서 자료 저장 위치 |
| 설정 | `%LOCALAPPDATA%\ResearchReportAutomation\config` | API 키, 키워드 설정 등 |
| 실행 기록 | `%LOCALAPPDATA%\ResearchReportAutomation\runs` | 수집 자료, PDF, 생성 보고서 |
| 리소스 | `%LOCALAPPDATA%\ResearchReportAutomation\resources` | 보고서 템플릿과 프롬프트 |

사용자 데이터 폴더를 삭제하면 실행 기록, 키워드 설정, API 키 저장 정보가 함께 삭제됩니다.

## 보고서 템플릿과 프롬프트 수정

보고서 생성에는 아래 파일이 사용됩니다.

```text
%LOCALAPPDATA%\ResearchReportAutomation\resources\report_template.docx
%LOCALAPPDATA%\ResearchReportAutomation\resources\report_prompt.md
```

- `report_template.docx`는 최종 워드 보고서 양식입니다.
- `report_prompt.md`는 보고서 bullet point 생성을 위한 프롬프트입니다.
- 두 파일을 수정하면 다음 보고서 생성부터 수정 내용이 반영됩니다.

템플릿의 변수명은 코드와 연결되어 있으므로, 변수명을 변경하면 보고서 생성이 정상적으로 되지 않을 수 있습니다.

## 생성 결과물

보고서 생성이 완료되면 실행 기록 폴더에 다음 파일들이 저장됩니다.

| 파일/폴더 | 설명 |
| --- | --- |
| `metadata.csv` | 수집 자료 메타데이터 |
| `metadata.xlsx` | 수집 자료 메타데이터 엑셀 파일 |
| `raw_pdfs` | 다운로드한 PDF 원본 |
| `report_data.json` | 워드 템플릿에 채울 최종 데이터 |
| `llm_output.txt` | LLM 응답 원문 점검용 파일 |
| `generated_report.docx` | 생성된 최종 보고서 |

## 삭제 및 초기화

앱을 제거하려면 Windows 설정의 앱 목록에서 `조사연구 도우미`를 제거하세요.

사용자 데이터까지 완전히 삭제하려면 아래 폴더를 별도로 삭제해야 합니다.

```text
%LOCALAPPDATA%\ResearchReportAutomation
```

이 폴더를 삭제하면 실행 기록, 키워드 설정, API 키 저장 정보가 모두 삭제됩니다.

## 유의사항

- 자료 수집과 보고서 생성에는 인터넷 연결이 필요합니다.
- 일부 언론사, 국가기관, 연구소 웹사이트는 구조 변경이나 접속 제한으로 수집이 실패할 수 있습니다.
- Google News 검색 결과는 검색어, 기간, 언론사 노출 정책에 따라 달라질 수 있습니다.
- 보고서 생성 결과는 반드시 사용자가 검토한 뒤 활용하세요.
- OpenAI API 키와 사용량 관리는 사용자 책임입니다.

## 개발자용 빌드 안내

설치 파일은 `build_installer.ps1` 스크립트로 생성합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build_installer.ps1
```

빌드가 완료되면 아래 파일이 생성됩니다.

```text
dist\ResearchReportHelperSetup.exe
```

현재 빌드 스크립트는 로컬 Python 런타임과 NSIS 설치 경로를 사용합니다. 다른 PC에서 빌드할 경우 `build_installer.ps1`의 경로 설정을 먼저 확인하세요.

기본 NSIS 경로:

```text
C:\Program Files (x86)\NSIS\makensis.exe
```

## GitHub 배포 방법

1. GitHub 저장소의 `Releases` 메뉴로 이동합니다.
2. `Create a new release`를 선택합니다.
3. 버전 태그를 입력합니다. 예: `v1.0.0`
4. 릴리스 제목을 입력합니다. 예: `조사연구 도우미 v1.0.0`
5. `dist\ResearchReportHelperSetup.exe` 파일을 첨부합니다.
6. 주요 변경사항과 설치 방법을 릴리스 노트에 간단히 작성합니다.
7. `Publish release`를 눌러 배포합니다.

사용자는 릴리스 페이지에서 설치 파일을 다운로드해 실행하면 됩니다.
